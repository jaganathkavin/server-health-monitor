# 🖥️ Server Health Monitoring System

A real-time server health monitoring application built using Python, Flask and psutil.

The project is containerized using Docker and designed for CI/CD deployment using Jenkins and Kubernetes.

## 🚀 Features

- CPU monitoring
- Memory monitoring
- Disk monitoring
- Network monitoring
- Server uptime
- Operating system information
- CPU core information
- Top processes
- Real-time dashboard
- Health check endpoint
- Docker containerization
- Jenkins CI/CD
- Kubernetes deployment
- Kubernetes liveness probe
- Kubernetes readiness probe

## 🛠️ Technologies
